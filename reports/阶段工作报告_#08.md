## MP-004 证明结构（严格忠实 §2 的 Gronwall 界）

1. **Euler 乘积** `sigma_div_le_prod_p_div_sub_one`：`σ(n)/n ≤ ∏_{p|n} p/(p−1)`，
   经 `Nat.sum_divisors`（σ(n) = ∏_p Σ_{k≤a_p} p^k）+ `geom_sum_le_pow_mul`（几何级数尾 ≤ p^a·p/(p−1)）+ `prod_factorization_pow_eq_self`。
2. **取 log**：`log(σ/n) ≤ Σ_p log(p/(p−1)) = Σ_p −log(1−1/p)`（`log_p_div_pred_eq_neg_log_one_sub`，经 `Real.log_inv`）。
3. **逐项放缩**：`−log(1−x) ≤ x + 2x²`（`neg_log_one_sub_le`，x≤1/2，经 `Real.log_le_sub_one_of_pos`）→ `log(σ/n) ≤ Σ(1/p + 2/p²)`；`Σ1/p² ≤ 1`（`sum_inv_sq_primes_le`，telescoping `1/(k(k−1)) = 1/(k−1) − 1/k`）。
4. **三重 log 拆分和** `sum_inv_primes_factors_le`（Gronwall 的 sharp 内核）：
   - 阈值 `M = Nat.log 2 m`（**全程无 floor**）；
   - 小素数 `p ≤ M`：`Σ ≤ Σ_{p≤M}1/p ≤ log log M + B`（引用 MP-005）；
   - 大素数 `p > M`：`Σ ≤ ω(m)/M ≤ M/M = 1`（`omega_le_log_two`，逐项 `1/p ≤ 1/M`）；
   - `M ≤ 2 log m`：由 `Nat.pow_log_le_self`（`2^M ≤ m`）取 log 得 `M log2 ≤ log m`，配 `log2 > 1/2`（证 `exp(1/2)² = exp 1 < 4`）得 `1/log2 < 2`；
   - `log log M ≤ log log log m + 1`（m≥8）：`log(log2 + t) = log t + log(1 + log2/t) ≤ log t + log2/t ≤ log t + 1`（用 `t = log log m ≥ log 2`，即 `log m ≥ 2 ⟺ m ≥ e²`，经 `exp 2 < 8` 由 `exp 1 < 2.72` 平方）。
5. **指数化**：`σ/m ≤ exp(log log log m + B + 4) = e^{B+4}·log log m`。
6. **小 m（3..7）**：`σ/m ≤ m+1 ≤ 8`（`σ(m) = Σ_{d|m}d ≤ τ(m)·m ≤ (m+1)·m`），配常数 `8/log log 3`（需 `log 3 > 1` 由 `exp 1 < 3`）。
