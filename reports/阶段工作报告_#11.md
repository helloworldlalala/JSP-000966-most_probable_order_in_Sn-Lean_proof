## 三、本轮踩坑记录（供后续会话参考）

- `rw [div_eq_mul_inv]` 会把指数内的除法（`5/2`、`17/20`）一并改写为 `* ⁻¹`，破坏后续
  rpow 引理的 pattern —— 必须用**显式参数版** `rw [div_eq_mul_inv (a := …) (b := …)]`。
- `Real.rpow_mul` 的 z 参数 `(2:ℝ)`（OfNat）与目标中 `↑2`（Nat.cast）不统一 —— 用
  `((2:ℕ):ℝ)`；`Real.rpow_add` 需 `0 < x`，`rpow_mul`/`rpow_neg`/`rpow_nonneg` 需 `0 ≤ x`。
- `rw` 无法匹配绑定变量下的元变量模式（`(∑ d₂, f ?d₁ d₂) * X` 在 `∑ d₁, …` 内）——
  改用 `apply Finset.sum_congr rfl; intro` 后逐点 `exact (Finset.sum_mul …).symm`。
- nlinarith 不统一除法原子（`(2C)/x` 与 `C/x+C/x`、`(1/2)/n²` 与 `(1/2)·(1/n²)`）——
  先 `field_simp` 建等式再 rw，或改用乘法形式。
- `^` 右结合：`(n:ℝ)^(-(17/20))^2` 解析为 `(n)^((−(17/20))²)`——平方整体必须加括号。
- `show … by ring` 的 rw 会把等式一侧出现的子项全部重写（如 `4*C` 在底数中也中招）——
  调整 rw 顺序或改用 calc 等式链。
- omega 对含指数/除法的上下文会失败（如 `n^2 ≠ 0`、`n/2 ≤ n−k`）——用
  `pow_ne_zero`、`Nat.le_sub_iff_add_le`、`not_lt_of_ge` 等直接构造。
- `Nat.le_induction` 的 P 依赖界证明（`P : ∀ n, m ≤ n → Prop`），需显式
  `(m := 6) (P := fun t _ => …)`。
- `abs_le : |a| ≤ b ↔ -b ≤ a ∧ a ≤ b`（分支顺序先 −b ≤ a）；三角不等式是 `abs_add_le a b`。
