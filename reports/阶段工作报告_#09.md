## 二、完成内容（零 sorry）

### 1. 圈删除双射 `cycleRemovalEquiv`

构造了论文 Cor 2.2 的组合心脏：

```
cycleRemovalEquiv {k} : {π : S_{n+1} // cycleLen π = k+1} ≃ (Fin k ↪ Fin n) × S_{n-k}
```

- 正向 `π ↦ (tupleOf π h, residualFwd π h)`：`tupleOf` 是有序的过 0 圈非零元组
  （`t i = predAbove 0 (π^{i+1} 0)`，注入性经 `IsCycle.pow_eq_pow_iff` + `orderOf` 整除）；
  `residualFwd` 是删除过 0 圈后的余置换。
- 逆向 `(t, σ) ↦ cycleThroughZero t * liftResidual t σ`：`cycleThroughZero` 用
  `finRotate(k+1) extendDomain orbitEquiv t` 重建圈，`liftResidual` 把 σ 提升到补集。
- left_inv：`cycleThroughZero_tupleOf`（圈恢复）+ `liftResidual_residualFwd` + `decompose_mul`。
- right_inv：`tupleOf_mul_liftResidual` + `residualFwd_mul_liftResidual`（经 `ofSubtype_injective`）。

### 2. 关键难点与解法

- **子类型对齐**：`liftResidual t` 用 complement `{x // ¬(x=0 ∨ ∃i, x=(t i).succ)}`，
  `residualSubtype π` 用 `{x // ¬ SameCycle π 0 x}`。二者命题等价但非 defeq，用
  `Equiv.subtypeEquivRight` + 自证 `ofSubtype_permCongr_subtypeEquivRight`
  （transporting 一个 subtype 置换不改底层置换）。
- **阶保持**：`orderOf_eq_lcm_cycleLen_residualFwd`（`orderOf π = lcm(k+1, orderOf(residualFwd π h))`）
  由 `orderOf_eq_lcm_cycleLen_residual` + 自证 `orderOf_residualFwd`（permCongr 是 MulEquiv，保阶）。
- **off-by-one**：MP-006/007 的 `n-1`/`d-1` 指标用 `cases n; cases d` 消去（`(n'+1)-1` 定义等于 `n'`），
  避免 `Equiv.cast` 的依赖类型运输。
- **n=1 边例**：S₁、S₀ 均为单点群，用 `Subsingleton`/`card_symmetricGroup`/`Fintype.card_eq_zero_iff` 单独处理。

### 3. Cor 2.2 的两个陈述（完整证明）

- `cycleLen_dvd_orderOf`：`cycleLen π ∣ orderOf π`（阶分解 + `Nat.dvd_lcm_left`）。
- `ord_dvd_prob_le_tau_div_n`：`P(orderOf π | m) ≤ τ(m)/n`（m≥1），
  经 `{ord|m} ⊆ {cycleLen|m}` + 均匀圈长纤维划分 + `n! = (n−1)!·n`。
