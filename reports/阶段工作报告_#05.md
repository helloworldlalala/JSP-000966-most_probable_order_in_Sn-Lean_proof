**MP-002（`tau_le_rpow` → `tau_pow_sixteen_le`）已解除为完整证明**（零 sorry）：

论文只陈述 `τ(m) ≤ m^{o(1)}`，并在 Theorem 1.1 中（因 `m ≤ n^{4/3}`）实际用到
`τ(m) ≤ C·m^{1/16}`。据此把接口忠实化为**纯 ℕ 形式** `∃ C, ∀ m, (tau m)^16 ≤ C·m`
（等价于 `τ(m) ≤ C^{1/16}m^{1/16}`），彻底规避了任意 ε 的 `Real.rpow` 机械化。

证明（逐素数二分）：
1. `Nat.card_divisors` 把 `τ(m)` 写成 `∏_{p|m}(a_p+1)`，`Finset.prod_pow` 升 16 次。
2. 素因子分 *small*（`p ≤ 2^16`）与 *large*（`p > 2^16`）两段（`Finset.prod_filter_mul_prod_filter_not`）。
   - 大素数：`(a+1)^16 ≤ 2^{16a} ≤ p^a`（`succ_le_two_pow`，`2^{16} ≤ p`）。
   - 小素数：`(a+1)^16 ≤ 2^{a+130} ≤ 2^{130}·p^a`（核心引理 `succ_pow_sixteen_le`）。
3. 相乘：`∏(a_p+1)^16 ≤ 2^{130·s}·∏ p^{a_p} = 2^{130·s}·m ≤ 2^{130·(2^16+1)}·m`，
   用 `Finset.prod_mul_distrib`/`prod_const`/`pow_mul` 与 `Nat.prod_factorization_pow_eq_self`，
   `s = #{小素数} ≤ 2^16+1`。

核心引理 `succ_pow_sixteen_le : (a+1)^16 ≤ 2^(a+130)` 用**强归纳**：基例 `a<30` 由
`(a+1)^16 ≤ 30^16 ≤ 2^80 ≤ 2^(a+130)`（单点 `norm_num`）；步用
`succ_pow_sixteen_le_two_mul`（`a≥30 ⟹ (a+1)^16 ≤ 2a^16`，经 `30(a+1) ≤ 31a` 交叉相乘）。
