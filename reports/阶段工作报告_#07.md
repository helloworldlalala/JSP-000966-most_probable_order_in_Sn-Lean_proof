## 成果

解除了 M2b 中体积最大的一条接口 sorry：**MP-005**（Euler 上界
`∃B>0, ∀x≥2, ∑_{p≤x} 1/p ≤ log log x + B`）。它是论文 §2 中「σ(m)/m ≪ log log m」
（MP-004）的直接输入，也是 Prop 3.1 E₂ 估计的解析数论地基。

证明忠实于论文引用「standard estimate」的标准路线，分两层：

### 1. Mertens 第一定理 `sum_log_div_primes_le : ∀x≥2, ∑_{p≤x}(log p)/p ≤ log x + log 4`

- **整除核**（此前已证）：`pow_natDiv_dvd_factorial`、`prod_pow_natDiv_dvd_factorial`
  （由 Legendre 公式 `Nat.factorization_factorial` 得 `p^{⌊x/p⌋} | x!`，进而 `∏p^{⌊x/p⌋} | x!`）。
- **取对数**：`real_prod_pow_natDiv_le_factorial` → `log ∏ ≤ log x!`（`Real.log_le_log`）→
  `∑ ⌊x/p⌋·log p ≤ log x!`（`Real.log_prod` + `Real.log_pow`）→ `log x! ≤ x log x`
  （`Nat.factorial_le_pow`）。
- **下界地板**：`⌊x/p⌋ ≥ x/p − 1`（自证 `cast_div_le_add_one`，经 `Nat.div_add_mod` + `Nat.mod_lt`）。
- **Chebyshev 收尾**：`x·∑(log p)/p − θ(x) ≤ x log x`，配合 `Chebyshev.theta_le_log4_mul_x`，
  除以 x 得 `∑(log p)/p ≤ log x + log 4`。

### 2. Abel 变换 → Euler 上界

- **Abel 恒等式** `abel_identity`：`∑_{p≤x}1/p = A_x/log x + ∑_{i=2}^{x-1}(1/log i − 1/log(i+1))·A_i`
  （`A_i = ∑_{p≤i}(log p)/p`），由 mathlib `Finset.sum_Ioc_by_parts` 直接导出。
- **Telescoping 界**：自证 `sum_Icc_sub_telescope`、`log_sub_div_le_log_sub`
  （核心不等式 `(y−x)/y ≤ log y − log x`，等价于 `log(1+t) ≥ t/(1+t)`，用
  `Real.one_sub_inv_le_log_of_pos`）、`sum_log_sub_div_le`、`sum_inv_log_diff_eq`。
- **组装**：`A_x/log x ≤ 1 + log4/log2`；`∑(1/log i − 1/log(i+1))·A_i ≤ (log log x − log log 2) + log4/log2`；
  得 `∑1/p ≤ log log x + B`，`B = 1 + 2·log4/log2 − log(log 2)`。

## 踩坑与要点（已记入 STATE.md conventions）

- `Real.log` 满足 `log(−x)=log x`，故 `Real.log_pow`/`Real.log_zpow` 无正性假设。
- 分部求和用 `Finset.sum_Ioc_by_parts`（比积分解 `AbelSummation` 轻量得多）；
  `range(x+1) = Icc 0 x` 经 `Finset.range_eq_Ico` + `Finset.Ico_add_one_right_eq_Icc`。
- `Real.log 2 < 1` 经 `Real.log_lt_iff_lt_exp` + `Real.exp_one_gt_two`；`Real.log_neg` 参数顺序为
  `(h0 : 0<x) (h1 : x<1)`。
- `log4/log2` 是原子乘积，最终 `nlinarith` 需先把 `log4/log2` 引入为单原子 `c` 再组合（避免非线性）。
- 逆单调性用 `one_div_le_one_div_of_le`（非 `inv_le_inv_of_le`）。
